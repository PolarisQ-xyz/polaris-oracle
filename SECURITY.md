# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **polaris-oracle**, please report it privately to the maintainers so we can address it promptly.

- **Email**: security@polarisq.xyz
- **PGP**: 0xDEADBEEF (public key available at https://github.com/PolarisQ-xyz/polaris-oracle)

Please include:
- A description of the vulnerability and its impact.
- Steps to reproduce the issue.
- Any relevant logs or screenshots.

We will acknowledge receipt of the report within 48 hours and provide a timeline for remediation. Details of the vulnerability will be disclosed responsibly after a fix is released.

## Responsible Disclosure

We appreciate responsible disclosure and will credit the reporter in the release notes, unless you request anonymity.
